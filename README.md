## Featured Project

### [LegendBar](https://github.com/Baldev8910/LegendBar)
A customizable Windows 11 top bar built with WinUI 3 and .NET 9. Acrylic glass, auto-hide, media controls, Pomodoro timer, clipboard history, quick notes, weather widget, and multi-monitor support.
